## 📲 PART 3 — OMNICHAT STRATEGY

### 3.1 What We'll Connect

TripNaari's website already has a **production-ready OmnichannelCRM** component with full pipeline management (Active → Qualified → Quote Sent → Payment Pending → Booked → Closed) and a built-in **Sales Drip Engine** (`lib/sales-engine.ts`). We need to connect the live APIs:

| Channel | API Needed | Status |
|---|---|---|
| WhatsApp | WhatsApp Business API (via BSP like Interakt/AiSensy) | To set up |
| Instagram DM | Meta Graph API (Instagram Messaging) | To connect |
| Website Chat | Already built in OmnichannelCRM | ✅ Ready |
| AI Bot | TripNaari AI CRM (`lib/ai-crm.ts`) | ✅ Ready |
| Drip Engine | `lib/sales-engine.ts` `runSalesDripEngine()` | ✅ Ready |

**BSP Recommendation:** Use **Interakt or AiSensy** (Indian BSPs) — cheapest official WhatsApp API access, ~₹999–₹2,499/mo for the platform, pays Meta per-message separately.

---

### 3.2 Bot Flow 1 — WhatsApp Enquiry Bot (Triggered from Meta/Google Ad)

```
User clicks "Chat on WhatsApp" from Ad
  ↓
BOT: "🌸 Hi! Welcome to TripNaari — Women-Only Group Trips!
      Which destination are you dreaming of?"
      [🏔️ Kashmir] [🌿 Meghalaya] [🌴 Kerala] [🏜️ Rajasthan] [🗺️ Custom]
  ↓
BOT: [Sends destination card — price, dates, highlights, 3 photos]
  ↓
BOT: "When are you planning to travel?"
      [📅 Sep–Oct] [📅 Nov–Dec] [📅 Just exploring]
  ↓
BOT: "How many Naaris are joining?"
      [Solo (just me)] [2–3 friends] [4+]
  ↓
BOT: "Great! Our team will send you a personalized itinerary within 30 mins.
      Drop your name and email so we can send the PDF too 📩"
  ↓
Lead captured → CRM pipeline (status: Qualified) → Agent assigned → Drip Step 0 starts
```

**Expected conversion:** 40–55% of WhatsApp starters → complete flow → CRM entry
